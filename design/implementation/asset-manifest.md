## Rules

- Keep reference screenshots under `design/references/direction-c/`; production code must not import them.
- Prefer one reusable illustration for the same concept across screen states.
- Use code-native icons for controls and status symbols. Generated raster assets are for character, object, and scene illustrations.
- Do not use a named character portrait for arbitrary dynamic household members unless profile-avatar behavior is added to the product.
- New visual variants remain review material until explicitly approved; the approved screen status is not changed by this manifest.
