# Visual Language

**Status:** Draft
**Direction:** Concept E

## Product personality

Chores should feel like a positive family tool for building independence.

Children should experience:

- clarity
- progress
- encouragement
- ownership
- reward
- confidence

Parents should experience:

- control
- confidence
- visibility
- calm
- fairness

## Age range

The product targets children approximately 8–18.

This means the design cannot rely on a single "kids app" aesthetic.

Use playful visual expression through:

- object illustrations
- color
- typography
- badges
- stickers
- encouraging copy

Avoid:

- cartoon overload
- babyish language
- excessive mascots
- confetti everywhere
- meaningless XP systems
- fake currencies

## Typography

Use a rounded, confident display style for large headings.

Use a neutral, highly readable UI sans-serif for functional information.

Display typography should make the app feel distinctive without reducing
readability.

## Color

Green communicates:

- progress
- action
- stability
- growth

Yellow communicates:

- reward
- opportunity
- positive attention

Coral communicates:

- urgency
- consequences
- important attention

Purple/blue may appear in secondary decorative or informational roles.

Semantic meaning should always be supported by text or iconography.

## Illustration

Chore illustrations should focus on recognizable objects:

- vacuum
- recycling bin
- bed
- dishwasher
- plants
- lawn mower
- car
- laundry basket
- pet
- broom

Prefer friendly object illustrations over cartoon faces on every card.

Character illustrations should be reserved for:

- onboarding
- celebrations
- empty states
- major encouragement moments

## Playfulness

Playfulness should come from:

- shape
- color
- copy
- small visual surprises
- illustration

not from hiding serious information.

Deadlines, locks, money, penalties, and review states must remain explicit.
