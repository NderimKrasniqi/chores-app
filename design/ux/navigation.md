# Navigation

- Child shell: floating control-deck tab bar (Quests, Extras, Family, Money; Family only with siblings); the same header on every tab with the avatar (profile); tapped notifications open the quest card, redo, Extras, or Family (a high-five).
- Parent shell: floating 4-tab bar (Home, Chores, Money, Family). Reviews open from Home's "to check" tile (Home carries the badge); a "submission to review" notification opens the deck.
- Pushed parent screens use a round back button (`ScreenFrame`).
- Tabs never slide; sheets use the platform slide; celebrations fade.
