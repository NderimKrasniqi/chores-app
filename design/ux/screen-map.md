# Screen map

## Child (quest theme)

- Onboarding → Who's using this phone? → Dock with your family (code / QR porthole) → Star-code PIN setup
- Star-code unlock (returning) · Lost signal (no access)
- Tabs: **Quests** (quest path, quest card) · **Extras** (chest gate, backpack, bonus quests, claimed quest card, lock sheet, unclaim keys) · **Family** (family sky + star log) · **Money** (piggy planet, rocket week, coins, last payday)
- Overlays: approval celebration, sibling toast, penalty notice, notification primer
- Quest passport (profile, lock & switch)

## Parent (home theme)

- Parent sign-in → Household setup (start / create / join with invite)
- Tabs: **Home** (mission control → review deck, crew → kid page, Extras in progress, latest win) · **Chores** (list + chore builder) · **Money** (payday board, slide to pay, balances) · **Family** (family orbit, kids, parents, invite, house rules)
- Pushed screens: Kid page (chores, coins, Extra, phones, rename/remove) · Link a phone (QR + code + countdown) · Account · Households · House rules · Family wins · Invite a parent
