## Product constraints preserved

- Chore earnings use real SEK, not points or game currency.
- A submission counts toward earnings only after Parent approval.
- Photo evidence is optional.
- Extras open only after the Parent-chosen Unlock Chore is approved.
- More complex commitment, unclaim, redo, penalty, privacy, and offline rules are explained contextually when relevant.

## Generation record

The assets were created with Codex built-in image generation.

- The style-anchor prompt requested a warm tactile, age-flexible Parent/Child UI system with stone surfaces, aubergine typography, mint and terracotta accents, rounded cards, clay-and-paper illustrations, real SEK, and no game economy.
- The onboarding prompt extended that visual system into four screens covering family value, the submit-and-approve loop, real SEK and Unlock Chore access, and Parent/Child role selection.
- A final targeted edit made photo evidence explicitly optional, added Back and Skip controls, corrected Unlock Chore language, removed implied savings features, broadened age representation, and strengthened role-card affordance.
- The Child Home prompt used the approved onboarding and Review-only style anchor to establish the Home destination. A targeted edit replaced a misleading lock icon with a key for the Unlock Chore and moved profile access to the avatar affordance.
- Child Home v2 removed the redundant `See all` route and established an independently scrollable `Your chores` viewport without scrolling the surrounding Home surfaces. That revision was then approved without further visual changes and renamed `child-home-approved.png`.
- The Parent Home prompt carried the approved visual system into a calmer, denser Parent surface with review-first hierarchy, quick chore creation, private Child summaries in real SEK, an active claimed commitment, explicitly approved activity, and fixed Parent navigation.
- Parent Home v2 separated `Add chore` from the review workflow and removed the duplicated approval status from Recent activity while preserving the approved monetary state in text.
- Parent Home v3 reserved coral for review and urgency by changing `Add chore` to mint/green, and removed the avatar's ambiguous dropdown badge. That revision was then approved without further visual changes and renamed `parent-home-approved.png`.
- The Child Extras pool prompt established the unlocked destination with an approved Unlock Chore state, weekly unclaim allowance, one-active-claim guidance, a bounded scrollable list, claim actions that lead to confirmation, and a sibling-safe `Claimed by Maya` state. It was approved without further visual changes and renamed `child-extras-pool-approved.png`.
