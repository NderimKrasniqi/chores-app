# Concept E — Selected Visual Direction

**Status:** Selected visual direction
**Authority:** Reference only — not an approved production screen

Concept E is the selected visual direction for Chores.

It should guide the production design system and screen exploration, but the
reference images themselves are not implementation specifications.

Approved HTML screens remain the visual source of truth.

## What we are keeping

### Personality

- playful
- optimistic
- motivating
- warm
- friendly
- expressive
- suitable for children and teenagers
- reassuring for parents

The product should feel like it helps children become more capable rather than
simply paying them to perform tasks.

## Visual characteristics

- warm off-white canvas
- deep green primary brand color
- fresh green secondary accents
- optimistic yellow reward color
- limited coral/red for urgency
- large rounded display typography
- soft rounded cards
- colorful task illustrations
- playful sticker-like elements
- occasional handwritten annotations
- simple progress visualization
- prominent but approachable money presentation
- icon + text state communication

## Child experience

The Child experience may be more expressive than the Parent experience.

Use:

- illustrated chore objects
- reward accents
- encouraging microcopy
- progress
- playful badges
- sticker-like visual details

Avoid making the experience look designed only for very young children.

The same UI should remain credible for a teenager.

## Parent experience

Parent screens use the same design system but reduce decorative elements.

The Parent experience should feel:

- calm
- operational
- trustworthy
- efficient
- family-oriented

## Important constraint

Concept E must not turn Chores into a game economy.

Real SEK remains real money.

Domain consequences such as missed locked commitments must remain clear and
serious even when presented in a supportive tone.
