# Status System

**Status:** Draft

Important statuses include:

- Available
- Due soon
- Claimed
- Locks soon
- Locked
- Submitted
- Waiting for review
- Approved
- Redo required
- Missed
- Failed
- Cancelled
- Paid
- Extras locked
- Extras unlocked

Status must never rely only on color.

Where appropriate combine:

- text
- icon
- color
- placement
