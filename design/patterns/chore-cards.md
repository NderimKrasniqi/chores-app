# Chore Cards

**Status:** Draft

Chore cards should prioritize:

1. Chore name
2. Current state / urgency
3. Deadline
4. Value
5. Relevant action

Do not overload the card with every possible piece of metadata.

## Personal chore

Personal chores should read as expected responsibilities.

Missing a Personal Chore earns nothing but never creates monetary debt.

## Claimable chore

Claimable chores should communicate extra earning opportunity and commitment.

After claiming, value and deadline are treated as accepted terms.
